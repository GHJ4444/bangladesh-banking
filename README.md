# Bangladesh banks data project 

The purpose of this project is to get machine-readable data on the Bangladeshi banking sector. The idea is to check on the solvency of the Bangladeshi banking system and seeing how that has changed over time. The two chief questions are what proportion of loans are non-performing and whether the sector has adequate capital.

Data has been pulled from the FRED API and sourced from the Bangladesh Bank banking sector update. That is available [here](https://www.bb.org.bd/en/index.php/publication/publictn/2/93). The link was accessed on October 27th.
